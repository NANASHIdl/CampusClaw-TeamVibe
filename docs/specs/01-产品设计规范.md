## 1. 用户与场景写死在 README 里

两类角色，六个场景，每个场景都必须落得到某个路由：

| 角色 | 场景 | 落到的路由 |
| --- | --- | --- |
| 教师 | 上传本班资料、看处理状态 | `/console` |
| 教师 | 查看本班提问记录与命中情况 | `/console/ask-logs` |
| 学生 | 浏览本班资料、打开详情看切片 | `/materials`、`/materials/:id` |
| 学生 | 检索本班资料 | `/materials`（顶栏检索框） |
| 学生 | 提问、追看出处 | `/ask`、`/sessions/:id` |
| 学生 | 回看自己的历史会话 | `/sessions` |

**判据**：每条能力在 `spec.md` 里出现时，都能在本表找到路由；找不到的，先回去改规约，再写页面。

## 2. 页面（路由）清单

| 路由 | 名称 | 准入 | 说明 |
| --- | --- | --- | --- |
| `/login` | 登录 | 免登录 | 邮箱 + 口令；成功后回跳 `?next=`，无 `next` 回 `/materials` |
| `/materials` | 资料列表 | 已登录 | 顶栏检索框 + 列表 + 上传入口（仅教师可见） |
| `/materials/:id` | 资料详情 | 已登录且本班 | 元信息 + 切片列表（按 `chunk_index` 升序）+ 原文下载 |
| `/ask` | 提问 | 已登录 | 输入框 + 流式回答 + 出处卡片 |
| `/sessions` | 我的会话 | 已登录 | 只列本人会话 |
| `/sessions/:id` | 会话详情 | 已登录且属本人 | 消息列表 + 出处卡片 |
| `/console` | 教师控制台 | 教师 | 上传、成员列表、资料状态 |
| `/console/ask-logs` | 提问记录 | 教师 | 分页表格：提问、命中数、模式、耗时 |
| `/404` | 未找到 | — | 越权与不存在的统一落点 |

路由守卫规则（`frontend/src/router/guards.ts`）：

- 未登录访问任何受保护路由 → 跳 `/login?next=<原路径>`，不弹提示。
- 已登录但角色不足（学生访问 `/console*`）→ 跳 `/404`，**不显示「无权限」**，避免泄露入口存在。
- 已登录访问 `/login` → 跳 `/materials`。

## 3. 术语表：一个概念只有一个词

| 面向用户 | 面向接口 | 禁止出现 |
| --- | --- | --- |
| 资料 | `material_id` | 文档、文件（**文件**专指上传的原始附件） |
| 切片 | `chunk_index` | 分片、段落（语义不同） |
| 出处 | `citation` | 引用来源、参考链接 |
| 班级 | `class_id` | 租户、群组 |
| 提问会话 | `session_id` | 对话（书面材料里不写「对话」） |
| 成员 | `membership` | 用户组 |
| 上传批次 | `upload_batch_id` | 批量任务 |

**同一屏出现两种叫法即为缺陷。** 判据：评审时在页面上搜「文档」「分片」「引用来源」三个词，命中即违规。

## 4. 视图状态必须枚举完

每个数据视图给出四种形态的文案模板，文案写在 `frontend/src/constants/copy.ts`，不在模板里硬写中文：

| 形态 | 触发条件 | 呈现 |
| --- | --- | --- |
| 加载中 | 请求发出至返回 | `el-skeleton`（列表 3 行 / 详情 6 行），**不用转圈遮罩** |
| 正常 | 200 且有数据 | 按组件清单渲染 |
| 错误 | 非 0 `code` 或网络失败 | `el-empty` + 错误文案 + 「重试」按钮；`1501`/`1502` 额外给「改用关键词模式」 |
| 空状态 | 200 且列表为空 | `el-empty`，文案按场景区分：本班暂无资料 / 你还没有提问记录 |

本项目的第五种形态——**检索无命中**（`code=0`、`hits=[]`）：

- 不显示空白列表，显示固定文案「资料中未找到相关内容」；
- 给出两个下一步动作：「换个关键词」「请本班教师补充资料」；
- **不得显示任何 `material_id` 或片段**，也不得把模型自由发挥的内容当作出处。

判据：把接口 mock 成 `hits=[]`，页面必须出现上面这句原文，而不是空表格。

## 5. 表单与校验时机

| 表单 | 即时校验（选择/输入时） | 提交时校验 | 提交后 |
| --- | --- | --- | --- |
| 登录 | 邮箱格式（失焦） | 非空、口令长度 8–72 | 失败 5 次锁 15 分钟，倒计时禁用提交 |
| 上传（`/console`） | 扩展名 ∈ `pdf/md/txt/docx`、单文件 ≤ 20 MiB | 单批 ≤ 20 个、本班资料总数 ≤ 500 | 通过后才有进度条；失败给文件名 + 原因 |
| 提问（`/ask`） | 无（不打断输入） | 长度 2–500 字符 | 发送后输入框禁用至流式结束或 30 秒超时 |
| 建班（教师） | 班名 2–40 字符 | 同上 | 成功后展示 8 位 `join_code`，可复制 |

- 校验提示统一走 `el-form` 的 `rules`，错误文案在 `copy.ts` 里，不写「输入有误」这种无信息量的话。
- 前端校验**只是体验**，服务端仍会拒绝；前端放过的请求被服务端拒时，按 §4「错误」形态展示。

## 6. 状态与流程

资料状态枚举（`status`）与允许的操作：

| 状态 | 含义 | 允许的操作 |
| --- | --- | --- |
| `pending` | 已入库，待处理 | 查看、删除 |
| `processing` | 解析切片中 | 查看（显示进度文案）、**不可检索** |
| `ready` | 可检索 | 查看、检索、下载原文、删除 |
| `failed` | 处理失败 | 查看失败原因、删除、重新上传 |

- 状态到页面的映射只允许出现上表四种值；出现第五种即为后端违约，前端按「错误」形态兜底并上报。
- 删除是软删：删除后列表立即消失，`/materials/:id` 再访问返回 404 页面。

## 7. 导入导出

- 导入仅指教师上传资料：单批 ≤ 20 个文件，整批校验（任一文件不合法则整批不提交），错误明细按**文件名 + 行号**列出。
- 提问记录导出（`/console/ask-logs`）：CSV，单次上限 5000 行，超出提示「请缩小时间范围」；导出内容不含学生邮箱明文，`user_id` 做短哈希。

## 8. 视觉基线按令牌写

只定义令牌与层级，不写每页像素值；令牌落在 `frontend/src/styles/tokens.scss`，覆盖 Element Plus 变量：

- 间距刻度：`8 / 16 / 24 / 32`（`--cc-space-1..4`），不使用 5、10、15 这类随手值；
- 字号层级三级：正文 `14px`、小标题 `16px`、页面标题 `20px`（覆盖 `--el-font-size-base` 等）；
- 语义色三项：成功 `--el-color-success`、警告 `--el-color-warning`、错误 `--el-color-danger`；
- 组件清单固定为：`el-button`、`el-input`、`el-form`、`el-upload`、`el-table`、`el-tag`、`el-skeleton`、`el-empty`、`el-pagination`、`el-dialog`、`el-message`。

新增页面必须复用清单中的组件；**出现自造样式（内联 `style` 或新建 `.css` 类）即判违规**，例外只能加进 `tokens.scss`。

## 9. 可达性与响应式下限

- 键盘可走完「登录 → 资料列表 → 资料详情 → 提问 → 看会话」全链路，焦点可见；
- 所有表单控件有关联 `<label>`（`el-form-item` 的 `label` 即可，不写占位符代替标签）；
- 正文与背景对比度 ≥ 4.5:1；
- 断点两档：`< 768px` 单列（表格转卡片列表），`≥ 1200px` 双列（左列表右详情）；
- 中文文案不出现「点击这里」，按钮文案用动词（「上传资料」「重新检索」）。

## 违反时

先确认是「实现偏好」还是「规范缺失」：前者改代码，后者改本文件并在变更说明里记录改动理由。若页面清单与术语表因此失同步，两处都改。
