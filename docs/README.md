## 维护规则

1. 改规范先在对应文件里改，再同步 `.cursor/rules/` 的摘要——两处不一致时以 `docs/specs/` 为准，但**摘要里的判据必须能被执行**。
2. 新增一节必须带「判据」；只写「应当如何」不写「怎么检查」的条目，会在下一次评审里被删。
3. 改 `docs/specs/` 属于需人审的变更（`docs/specs/08` §8），提交信息要写清改了什么、为什么、怎么验证。
